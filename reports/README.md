# Розрахунки Victory Hall

Панель відкривається через **Інженерний режим → Розрахунки по будинку**.
Кнопка розміщена всередині меню та не перекриває поверхи чи нижню картку.

## Два сервіси

- **Сервер · Python / SQL** — чинне захищене API, звіти показуються в панелі моделі.
- **Google Apps Script** — окремий наявний сервіс, відкривається явним натисканням
  посилання в новій вкладці. Це не JSON-адаптер і не вбудована копія його звітів.

Вибір Apps Script скасовує поточний Python-запит і приховує його результати;
запізніла відповідь не застосовується. При поверненні можна продовжити роботу з Python.
Підтверджений доступ залишається тільки в пам'яті вкладки та не передається Google.
Невідправлене персональне посилання очищається при перемиканні сервісу.
Автоматичного fallback, об'єднання результатів або твердження про їхню тотожність немає.
Права доступу двох сервісів незалежні; відкриття посилання не гарантує доступу до Apps Script.

## Поділ відповідальності

- GitHub Pages зберігає інтерфейс і модель.
- Захищений серверний API обчислює звіти та читає SQL.
- Геометрія `m/`, дані `d/` і вбудований код моделі цим модулем не змінюються.
- Ключ атласу та персональний доступ до серверних звітів — різні механізми.
- Ключі, персональні посилання, SQL credentials і записи відключень у цей модуль не вбудовуються.

API endpoint заданий повною HTTPS-адресою й перевіряється за точним списком дозволених адрес.
Сервер має дозволяти CORS для `https://mischenkoa85-creator.github.io` лише на читальних маршрутах
`/v1/reports/catalog`, `/v1/reports/periods`, `/v1/reports/outages` та POST `/v1/reports/query`.
Персональна авторизація обов'язкова незалежно від CORS. Cookies не використовуються.

## Дані й вихід

Перелік місяців і відключення надходять із SQL при запиті. Пропущені дні не прирівнюються до нуля;
підтвердження власником відокремлене від інструментальної перевірки напруги.

Доступ зберігається лише в пам'яті вкладки. Закриття панелі скасовує поточний запит;
запізніла відповідь не повинна відновлювати приховані дані. «Від’єднати доступ» також очищає
доступ і повертає до моделі. Після перезавантаження вкладки може знадобитися повторний вхід.

Розміщення клієнта на GitHub не доводить працездатність API або фізичного телефона:
потрібні окремі перевірки CORS, авторизації, SQL-відповідей і керування після виходу.

Локальні перевірки без мережі:

```text
node --check reports/panel.js
node tools/test_reports_endpoint.cjs
node tools/test_reports_services.cjs
python tools/test_reports_source.py
```
