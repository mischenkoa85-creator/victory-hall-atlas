ЧАСТИНА Б. ЗНАЧОК ЖИВЛЕННЯ (окремо, після підтвердження власника)

Власник ще має підтвердити:
- хто передає дані біля інвертора: компʼютер Windows чи ESP32;
- що цей пристрій разом із роутером живиться від резервної лінії.

1. Адреса стану — GET, JSON, без cookies, лише читання, без персональних даних:
   { "grid": { "state": "on|off", "since": "ISO-8601", "outages_today": 0 },
     "pv": { "kw": 0.0, "today_kwh": 0.0 },
     "battery": { "soc": 0 },
     "updated": "ISO-8601" }
   - since — час останньої зміни стану мережі.
   - CORS: Access-Control-Allow-Origin для https://mischenkoa85-creator.github.io і для походження VPS; без credentials.
   - Сторінка питає стан раз на 10 с, поки її видно. Дані старші за 60 с показуються як «Немає даних». Поріг «генерація є» — 0,3 кВт, задано на сторінці.
2. Ланцюг на сервері (за концепцією власника):
   - відправник біля інвертора → MQTT 8883 з TLS, окремий логін на пристрій;
   - далі буфер → підсумки кожні 5 хв у SQL;
   - буфер звільняти лише після перевірки запису;
   - зникнення мережі на 15–30 с і довше — подія з тривалістю в SQL; на сторінці стан «Відсутня мережа» має зʼявитися не пізніше ніж за 30 с;
   - адреса стану віддає останній стан.
3. Безпека: паролі й ключі Deye та MQTT — лише на сервері й пристрої. У сторінку і сховище вони не потрапляють.
4. Коли адреса готова — повідомте її. POWER_URL вписується в сторінку окремим запитом на злиття.
