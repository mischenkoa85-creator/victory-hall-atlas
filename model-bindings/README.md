# Прив’язка приміщення №421

Виправлення від 18.10.2026 пов’язує наявний об’єкт `R-421` на модельному рівні
`0` (Цоколь) з наявним обліковим ключем `nonres:421`. Нові приміщення та SQL-записи
не створюються. Бінарні блоки геометрії, координати контурів і зашифровані файли не змінюються.
У наявного контуру №13 змінено лише обліковий ключ `u`: `null` → `nonres:421`.

Джерело підсумку: експорт приміщень ДАХ від 08.10.2026,
SHA-256 `1aba60e8d9671f10c6f85307461515134b97656f17f1c7d1c8b8717f92ffc64d`.
Він містить 12 окремих нежитлових приміщень: №1–11 та №421.
Площа №1–11 — 584,2 м²; №421 — 10,3 м²; разом — 594,5 м².
Геометрична площа контуру R-421 — 9,1 м². Обидві величини збережені з різним змістом.

Корекція застосовується після завантаження моделі та можливого розшифрування знімка.
Вона виправляє лише загальну картку кількості/площі, навігацію й публічну ідентичність.
Старі фінансові суми, база розподілу площі, тарифи та покази не перераховуються.
Повний приватний паспорт №421 не створюється з вигаданих або нульових значень.
Свіжа SQL-звірка та доповнення закритого паспорта залишаються окремими кроками.

При невідповідності об’єкта, поверху або зайнятому ключі прив’язка не застосовується.
При зміні версії/підсумку ДАХ старе виправлення не накладається на нові числа.

Перевірка: `node tools/test_unit421.cjs`.
